# AI Settings Dialog Manual Test

1. Build and run the Blazor Server app.
2. Log in to the application.
3. Open the settings menu and select **AI / Model Settings**.
4. In **Provider Editor**, try saving with the **Name** field empty and confirm validation prevents the save.
5. Enter a provider name and click **Save**. A success snackbar should appear and the provider should show in the **Providers** tab.
6. Use **Test Connection** and **Refresh Models** buttons to see loading states and snackbars.
7. In **Quick Chat Test**, select the provider and model, send a message, and view the echoed response.
